## Repository Contents:   

- **CCNP_SP_CORE_AUTOMATION**  
This directory contains the Markdown, Python, YAML, and JSON files created to prepare for the CCNP SP Core Network Automation sections.

- **HarvardX_CS50x**  
This directory contains the Python, SQL, HTML, Java, and CSS files created to complete assignments and projects for Harvard's CS50 Introduction to Computer Science.

- **Palo Alto Panorama Rule Decommissioning Script**  
This directory contains the Python script created to automate the decommissioning of security rules in Palo Alto Panorama. The script reads rule details from an Excel file, generates the corresponding CLI commands, and writes them to a text file for easy execution.
