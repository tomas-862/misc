# README for SPCore

The **spcore** directory contains markdown (.md) and Python (.py) files designed to help you prepare for the automation sections of CCNP Service Provider (SP) core exam. These scripts cover various topics and concepts essential for the exam, providing a practical approach to understanding the material.

NOTE:
The **fun_Net_Automation_with_PY** directory covers FUNdamentals of network automation.  
The **adv_Net_Automation_with_PY** directory covers ADVanced topics of network automation.

AI model (GPT-4o) have been used to improve .md and .py work files (style, strucure).
