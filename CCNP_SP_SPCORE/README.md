# CCNP Service Provider Core (SP Core) Preparation

Welcome to the **spcore** directory! This repository is designed to assist you in preparing for the automation sections of the **CCNP Service Provider (SP) Core** exam. Here, you'll find a collection of Markdown (.md) and Python (.py) files that cover key topics and concepts essential for understanding automation in networking.

## Repository Contents

- **1_Automation_basic_PY/**: 
  - This directory focuses on the basics of network automation. It includes foundational scripts that introduce core concepts, helping you build a solid understanding before tackling more complex topics.

- **2_Automation_advanced_PY/**: 
  - This directory delves into advanced network automation topics. The scripts here are designed for those looking to deepen their skills and knowledge, preparing you for the intricate challenges presented in the CCNP SP Core exam.
