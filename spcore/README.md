- **Bold Text**: You can make text **bold** by wrapping it with double asterisks.
- **Italic Text**: You can also make text *italic* by wrapping it with single asterisks.
- **Lists**: Using `-` or `*` allows you to create bullet lists:
  - Item 1
  - Item 2
- **Code Snippets**: Inline code can be denoted with backticks, e.g., `print("Hello World!")`.
