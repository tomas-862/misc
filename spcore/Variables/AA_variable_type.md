# Checking Variable Types in Python

In Python, you can check the type of a variable using the built-in `type()` function.

## Example

```python
num = 20           # This is an integer
text = "20"       # This is a string

# Check the type of the variable 'num'
print(type(num))  # Output: <class 'int'>

# Check the type of the variable 'text'
print(type(text)) # Output: <class 'str'>
